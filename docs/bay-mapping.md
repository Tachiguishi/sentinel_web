# 装置与间隔配置

在站点详情中更新 SCD 后，点击“装置与间隔配置”。当前站点名称对应 MySQL 的 `F1041_CODE`。

站点详情左侧按“电压等级 → 间隔 → 装置”展示，可分别折叠电压和间隔。未配置或对应间隔已不在当前厂站目录中的装置，统一放在最上方的“0kV → 未知间隔”；其余电压等级从高到低排列。搜索装置时自动展开匹配分组，原有装置查看和批量修改类型功能继续可用。

页面按厂站代码从 `TB1042_BAY` 查询 `F1042_CODE`、`F1042_NAME`、`F1042_DESC`、`F1042_VOLTAGE`，不修改 MySQL 间隔目录。

- 拖动整张装置卡片（名称、描述或空白区域）到间隔卡片即可配置；勾选多个装置后，拖动任意已选装置卡片可批量配置。
- 左侧只显示尚未分配间隔的装置；分配后立即移至右侧对应间隔，撤销或移出后重新出现在左侧。
- 也可以勾选装置后点击目标间隔的“分配所选装置”，支持键盘和触屏操作。
- 点击右侧间隔中的“移出”可解除关联；目录中已不存在的间隔，可在提示区点击“解除关联”。
- 点击“筛选间隔”旁的“刷新”，重新从 MySQL 查询当前厂站间隔目录；保留搜索条件、装置选择和未保存的配置，刷新失败时保留原目录。
- 点击“保存配置”持久化；“撤销修改”恢复到最近一次加载或保存的状态。

每个装置最多对应一个间隔，每个间隔可以包含多个装置。关联保存在厂站独立的 SCD SQLite 数据库中，使用现有 `device.bay_id` 关系；间隔保存 MySQL 代码、名称、描述和电压快照。再次导入 SCD 时，同名装置保留关联，新装置默认为未分配，SCD 中已删除的装置按原有导入逻辑移除。

旧 SQLite 数据库在第一次保存配置或更新 SCD 时自动补充 `bay.code`，并修复旧版间隔 ID；只读访问不修改数据库。无需执行 MySQL 表结构迁移。

模型导出包含装置的 `bay`（间隔代码）、`bayName`（间隔名称）和 `voltage`（按现有规则编码，目录电压按 kV 保存）。如使用 `~/.config/sentinel/sentinel.xml` 自定义导出配置，需要在 `TB1046DAO` 中加入 `<column id="bay" name="F1042_CODE" type="String" valid="true" />`。

接口：

- `GET /api/stations/bays?name=厂站代码`：查询厂站间隔目录。
- `GET /api/stations/scd/bay-mappings?name=厂站代码`：查询装置及当前间隔代码。
- `PUT /api/stations/scd/bay-mappings?name=厂站代码`：批量保存变更，成功返回 204。请求体为 `[{"device":"IED1","bayCode":"Bay001"},{"device":"IED2","bayCode":null}]`，`null` 表示解除关联。

保存仅更新请求中的装置。服务端拒绝重复装置及跨厂站间隔；如果任何装置不存在，整批回滚。页面保留保存失败的修改，可重试或重新加载。
